BNTS 3D printing test files

All dimensions are in millimetres. All files are small and can be uploaded without editing.

example-cube-20mm.stl
One closed 20 x 20 x 20 mm cube. Expect a clean model check. Try scaling it to 150% (30 mm).

example-colour-sections.obj
One closed 30 x 20 x 12 mm block with two joined colour sections. Expect Section 1 and Section 2. Choose one colour for each section. Vertex colours are included in the OBJ; no MTL file is needed.

example-multipart-nut-and-bolt.stl
Two separate closed objects resting on the print bed: an unthreaded bolt shape and a nut-shaped ring. Expect a separate-object message. Select Convert to separate files, then choose different colours, scales, copies or notes for each file. These are demonstration shapes, not threaded hardware.

example-floating-2mm-gap.stl
A 30 x 24 x 4 mm base with a 12 x 8 x 3 mm tab suspended above it. The air gap is exactly 2 mm. Keep it as one file to test the red floating-area highlight and Test print falling animation. Turn on Print with supports to hold the tab in place, then select Remove supports to see it fall away. Supports do not join the tab to the base. Converting it to separate files places both objects on the bed, so the floating issue will then disappear.

example-cad-upload.zip
Contains all four CAD examples above, this guide and a small PNG image. Upload the ZIP directly to check that only the four CAD files are kept. Extract it on your computer if you want the individual files. The guide and PNG should never appear as print submissions.
